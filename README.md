# Summary

Hello, everyone! :)

In partnership with the **Mentor and Tutor Center of Lviv Polytechnic National University**, we are pleased to present an introductory course on **General Cybersecurity**.

This course is designed for students who want to gain a broader understanding of the current cybersecurity landscape, explore key industry challenges, and learn more about career opportunities and the cybersecurity job market.

**The main goal** of this collaboration is to help students build and strengthen their professional portfolios by working together on practical projects based on realistic cybersecurity scenarios.

**Duration and workload**

The programme is expected to run for approximately **6 months**. It will include up to **10 hours of classes**, as well as consultation sessions. In addition, each student is expected to dedicate approximately **50 hours** to working on their group project.

**Three learning tracks are planned:**

## Track 1 — Architecture and Compliance

| Work stage | Task description | Hours |
|---|---|---:|
| 1. Architecture familiarization | Analyze the infrastructure, system components, network segments, and key assets | 8 |
| 2. Security requirements and policies | Define security requirements and develop access control rules, policies, and protection recommendations | 12 |
| 3. Threat detection use cases | Identify potential threats and develop detection use cases and SIEM monitoring rules | 10 |
| 4. Standards compliance | Assess the developed security requirements and rules against relevant standards and best practices | 10 |
| 5. Results analysis and improvement | Review testing results, analyze penetration testing and digital forensics reports, and revise security policies and rules | 10 |
| **Total** | | **50** |

## Track 2 — Digital Forensics and SOC

| Work stage | Task description | Hours |
|---|---|---:|
| 1. Familiarization with tools | Get familiar with Wazuh, its architecture, configuration, and available log sources | 5 |
| 2. Log collection and event detection validation | Verify log ingestion, agent operation, and the correct triggering of existing detection rules | 7 |
| 3. Attack monitoring | Monitor the system during controlled attacks, collect and perform an initial analysis of security events | 10 |
| 4. Digital forensics | Investigate logs and collected artifacts, reconstruct the sequence of events, and create an incident timeline | 15 |
| 5. Reporting and recommendations | Prepare an incident investigation report and recommendations for improving monitoring and incident response | 13 |
| **Total** | | **50** |

## Track 3 — Penetration Testing

| Work stage | Task description | Hours |
|---|---|---:|
| 1. Architecture familiarization | Study the lab environment architecture, its components, and the defined testing scope | 5 |
| 2. Attack surface analysis | Identify potential entry points, vulnerable components, and possible attack vectors | 7 |
| 3. Attack scenario development | Develop up to 5 security testing scenarios, defining objectives, prerequisites, and expected outcomes | 10 |
| 4. Security testing | Conduct controlled security tests based on the defined scenarios and collect evidence | 18 |
| 5. Reporting and recommendations | Prepare a penetration testing report describing identified issues, assessing their impact, and providing remediation recommendations | 10 |
| **Total** | | **50** |
